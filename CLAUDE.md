# Sneak

iOS social game. Designs are in Figma, file key `YPJMBELCIik1hbaE8RnDBn`.

Before opening Figma, read `Sneak-Build-Map.md`. It lists every screen's node ID, the components it uses, and the navigation. Request single screens by node ID, never whole pages.

When a screen is added or changed, update the build map in the same commit.
